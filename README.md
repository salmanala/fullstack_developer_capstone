# fullstack_developer_capstone

This project is a full-stack web application for Cars Dealership, a national car retailer in the United States.

The application allows users to:
- View dealership branches
- Filter dealerships by state
- View dealer details and reviews
- Register and log in
- Submit dealership reviews
- Perform sentiment analysis on reviews

Technologies used include Django, React, Flask, Node.js, MongoDB, SQLite, Docker, Kubernetes, GitHub Actions, and IBM Cloud Code Engine.
